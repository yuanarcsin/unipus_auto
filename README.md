# Unipus Auto

U 校园（Unipus）自动答题工具，包含浏览器扩展、Python 独立脚本和 Java 桌面应用。

| 子项目 | 说明 | 位置 |
|--------|------|------|
| 浏览器扩展 | Chrome/Edge 插件，推荐 | [AutoUnipus/extension/](AutoUnipus/extension/) |
| Python 脚本 | Playwright 独立答题 | [AutoUnipus/](AutoUnipus/) |
| Java 桌面应用 | 全功能桌面客户端 | [UnipusHelperPro/](UnipusHelperPro/) |

## 使用

扩展安装：`edge://extensions` → 开发人员模式 → 加载解压缩 → 选择 `AutoUnipus/extension/`

详见各子项目内的 README。
